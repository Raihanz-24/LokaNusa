## Keputusan Arsitektur Penting
- **D-001**: Database = **MySQL 8** (driver `pdo_pgsql` & `pdo_sqlite` tidak tersedia di lingkungan). Menyimpang dari preferensi PostgreSQL di PRD; disetujui pemilik proyek.
- **D-002**: Test DB = MySQL `loka-nusa-test`; `phpunit.xml` diubah di Step 2.
- **D-003**: Filament **v5** sebagai basis UI admin (bukan v3).
- **D-004**: Modular monolith, business logic di `app/Domain` + `app/Services`, terpisah dari Filament.
- **D-005**: RBAC berbasis **enum** (`UserRole`+`Permission`) + Gate + Policy. Alasan: peran stabil, hindari tabel tambahan; mudah dimigrasi ke tabel bila perlu.
- **D-006**: Panel admin tetap **Filament** (berbasis Blade). Sisi **publik (PWA, Step 7+) memakai Blade** (bukan Filament). Dipilih oleh pemilik proyek.
- **D-007**: Halaman publik memakai Blade + Vite/Tailwind v4, layout `resources/views/components/layouts/public.blade.php`, komponen kartu `destination-card`. Hanya destinasi berstatus `published` yang tampil (dijaga `scopePublished()` + query).
- **D-008**: **Ruang lingkup = satu kabupaten/kota** (ditetapkan Super Admin). Kuliner/restoran = bagian modul **UMKM** (`business_type`); **penginapan** = modul terpisah. Ownership per akun + admin kelola semua (dikonfirmasi pemilik proyek).
- **D-009**: Status moderasi **generik** `ContentStatus` (draft/pending/published/rejected/archived), dipakai lintas modul (destinasi/UMKM/penginapan). `DestinationStatus` lama dihapus/digabung.
- **D-010**: Wilayah tidak menyediakan data **desa** secara bawaan → desa diambil **on-demand** untuk **kabupaten fokus** via `wilayah:import-villages` (sumber wilayah.id), disimpan di tabel `regions` (`type = desa_kelurahan`). Form memakai **dropdown desa berjenjang** (kecamatan → desa) via `village_id` (FK `regions`). (Diperbarui tahun 2026-10-12; sebelumnya desa = teks bebas.)
- **D-011**: Peta memakai **Leaflet + OpenStreetMap via CDN** (gratis, tanpa API key) dengan `MapPicker` untuk klik koordinat. Provider berbayar ditunda.
- **D-012**: **Koordinat (lokasi maps) WAJIB** saat menambah destinasi/UMKM/penginapan (`latitude`/`longitude` required). "Peta khusus aplikasi" (halaman peta jelajah) = Step 8; di pondasi ini koordinat wajib + `MapPicker` klik.
- **D-013**: Destinasi **boleh dikelola pemerintah** — field `Pengelola` dapat diisi akun mana pun yang berperan (termasuk admin pemerintah). Tidak ada pembatasan pemilik selain policy.
- **D-014**: **Auto-isi alamat dari peta** memakai **reverse geocoding Nominatim/OpenStreetMap** (gratis, butuh internet, batas ±1 permintaan/detik) via trait `ReverseGeocodesAddress`. Hasil dicocokkan ke kecamatan/desa dalam kabupaten fokus berdasarkan **nama** (`RegionResolver::normalize`); bila tidak cocok, pengguna memilih manual. Tidak ada penyimpanan alamat ke layanan berbayar.
- **D-015**: **LokaCulture** = artikel budaya (`CultureArticle`) dengan `CultureType`, ditulis per akun (`author_id`, peran `kontributor_budaya`) atau admin; alur moderasi memakai `ContentStatus` yang sama (`CultureArticleService`). Isi artikel disimpan sebagai teks (tanpa editor WYSIWYG pihak ketiga); tautan wilayah opsional (kecamatan/desa).
- **D-016**: **Autentikasi publik** memakai guard `web` (sama seperti admin, tanpa tabel baru) dengan peran `wisatawan`. **Hanya beranda** yang dapat diakses tamu; halaman publik lain dilindungi middleware `public.auth` (`EnsurePublicAuthenticated`) → tamu diarahkan ke beranda + popup ajakan masuk/daftar (tanpa memaksa redirect ke halaman login). Tautan/tombol/form internal untuk tamu disasar via JS (`auth-prompt`) dan tidak berpindah halaman. Login/daftar di `/masuk` & `/daftar`; keluar `POST /keluar`. Tujuan awal disimpan sebagai `url.intended` lalu dilanjutkan setelah login (redirect hanya path internal, anti open-redirect).
- **D-019**: **Data dummy pengembangan** disediakan lewat `DummySeeder` (3 destinasi + 3 UMKM di kabupaten fokus, gambar dari aset lokal), **tidak** dipanggil oleh `DatabaseSeeder` default agar produksi bebas data palsu. Jalankan manual: `php artisan db:seed --class=DummySeeder` (idempoten). Beranda baru menampilkan konten `is_recommended`/kurasi; konten umum tetap tampil di halaman daftarnya.
- **D-020**: **URL aset penyimpanan bersifat relatif** (`filesystems.disks.public.url` = `/storage`, dapat ditimpa `APP_ASSET_URL`) agar gambar tetap tampil tanpa bergantung pada `APP_URL` — mencegah gambar gagal muat saat aplikasi dibuka lewat host/port berbeda (mis. `loka-nusa.test`, `127.0.0.1:8000`).
- **D-018**: **Konten beranda dikelola Super Admin** (tanpa data contoh palsu). Tiga tabel: `home_banners` (gambar/caption/tautan/urutan/aktif) → resource **Banner Beranda** (grup "Beranda", permission `manage-settings`); `home_shortcuts` (label/ikon Heroicon/tautan) → resource **Shortcut Beranda**; `recommendation_items` (polymorphic ke Destinasi/UMKM/Penginapan) → resource **Rekomendasi Beranda** (kurasi manual prioritas). Tersedia pula flag `is_recommended` + `recommendation_order` pada destinasi/UMKM/penginapan sebagai fallback. Carousel geser otomatis tiap 3 detik (vanilla JS, tanpa Alpine). Ikon shortcut Heroicons **ditanam inline** di komponen `x-heroicon` (agar beranda tidak bergantung bundel Filament). Bila tabel banner kosong, beranda memakai gambar Bromo bawaan (aset lokal).
- **D-017**: **Autentikasi publik memakai kode Laravel Breeze** (`laravel/breeze` v2.4, dev-dependency) via **adopsi selektif stub** (`app/Http/Controllers/Auth/*`, `app/Http/Requests/Auth/LoginRequest.php`, `ProfileController`, `routes/auth.php`, view `auth/*` & `profile/*`, layout tamu). **Installer `breeze:install` TIDAK dijalankan** supaya `vite.config.js`, `resources/css/app.css` (Tailwind v4), `app.js`, `package.json`, dan `routes/web.php` tidak tertimpa. Manfaat keamanan standar Laravel: rate-limit login (`RateLimiter`, 5 percobaan + `Lockout`), session regenerate/invalidate, reset kata sandi (`password_reset_tokens`), verifikasi email, konfirmasi kata sandi. URI tetap berbahasa Indonesia; nama rute mengikuti Breeze (`login`, `register`, `logout`, `password.*`, `verification.*`, `profile.*`). Perilaku gerbang + popup D-016 dipertahankan; redirect setelah auth memprioritaskan parameter `redirect` (path internal aman) → `url.intended` → beranda.
- **D-021**: **Event & Agenda** = modul `Event` (judul/slug, `EventType`, jadwal `starts_at`+`ends_at`, lokasi + koordinat opsional, gratis/harga tiket, penyelenggara + kontak, sampul/galeri, moderasi `ContentStatus`). Dikelola per akun (`organizer_id`, peran `pengelola_event`) atau admin (permission `manage-events`). Halaman publik `/event` menyediakan **filter tanggal** (tab masa: akan datang / sudah lewat / semua, filter bulan, jenis, pencarian) dan `/event/{slug}`. Modul ini menjadi tujuan shortcut beranda "Event". Hanya `published` yang tampil.
- **D-022**: **Engagement wisatawan** (Step 13) = **Favorit** + **Ulasan**, keduanya **polymorphic** ke destinasi/UMKM/penginapan/event. Favorit (`favorites`, unik per pengguna+konten) bersifat ringan (toggle). Ulasan (`reviews`) menyimpan rating 1–5 + komentar dan **langsung terbit tanpa antrean moderasi** (keputusan pemilik); **hanya super admin** dapat melihat daftar ulasan di panel (`/admin/reviews`) dan **menghapus** ulasan yang melanggar (mis. SARA) — admin pemerintah/wilayah tidak. Satu pengguna maksimal satu ulasan per konten (bisa diperbarui). Jenis konten dipetakan di enum `EngagementType` (dipakai rute publik `{type}` + nama rute detail), bukan nama kelas penuh. Hanya konten `published` yang dapat difavoritkan/diulas (dicek server-side). Rata-rata & jumlah rating (`withAvg`/`withCount` pada `publishedReviews`) ditampilkan di kartu daftar & halaman detail; input rating memakai komponen bintang interaktif (`x-star-input`) yang menyalakan semua bintang 1..N saat dipilih.
- **D-030**: **AI Trip Planner (fondasi UI chat bot)** — halaman chat bot `/ai-trip-planner`, **wajib login** (grup `public.auth`, tamu → beranda + popup). **Belum memakai AI/API nyata**: balasan disusun lokal & deterministik oleh `TripPlannerService` (mesin aturan kata kunci: sapaan, durasi, minat kuliner/budaya/alam, anggaran, peta, terima kasih, fallback), memakai konteks wilayah fokus (`RegionResolver`). Titik integrasi AI nyata terisolasi di `TripPlannerService::reply()` sehingga controller & tampilan tak perlu berubah. Riwayat percakapan disimpan **per pengguna di database** (`trip_planner_messages`) sehingga **tidak hilang saat berpindah halaman**; **kuota 100 prompt/hari/pengguna** (`trip_planner_usages`, terlampaui → HTTP 429 + pesan) dan **riwayat dibatasi 100 pesan** (yang tertua otomatis dihapus). Endpoint: `GET /ai-trip-planner`, `POST /ai-trip-planner/kirim` (JSON), `DELETE /ai-trip-planner` (reset). UI: layout publik (opsi **`full-height`**) — panel tinggi layar: **area pesan mengalir & menggulir sendiri**, **kolom ketik + chip saran terkunci di bawah**, header asisten statis + **badge sisa kuota harian**; footer & bottom nav disembunyikan di halaman ini. **Panel alat mengambang** (kanan bawah, tepat di atas kolom ketik) berisi **tombol kembali ke atas** (muncul saat tergulir) & **tombol reset**. Komponen **`x-chat-bubble`**, kolom kirim `textarea` auto-grow (Enter kirim, Shift+Enter baris baru), banner **disclaimer demo**. Navigasi: tautan di **nav desktop** + **menu tiga-titik**; shortcut beranda bawaan **“AI Trip Planner”** diarahkan ke `/ai-trip-planner` (ikon `Sparkles`). Utilitas `scripts/check_translations.php` memverifikasi keseimbangan kunci EN/ID. Bahasa UI chat mengikuti switch ID/EN.

- **D-032**: **AI Trip Planner — AI nyata & pencatatan token.** Penyedia: **gateway kompatibel OpenAI** (mis. ## Risiko Terbuka
- Filament v5 API baru; jaga sumber daya referensi sesuai versi.
- Galeri & fasilitas disimpan sebagai JSON — cukup untuk MVP.
- Kategori destinasi: relasi tunggal (FK). UMKM: banyak produk via relasi.
- **Peta & CDN Leaflet butuh internet**; tanpa internet peta tidak tampil (data tetap tersimpan).
- Dataset wilayah bawaan tidak memuat **desa**; desa diimpor per kabupaten fokus (lihat D-010) dan butuh internet saat impor.
- **Auto-isi alamat (Nominatim)** butuh internet dan akurasi pencocokan nama desa/kecamatan bergantung data OSM; bisa gagal → fallback pilih manual.
- Ruang lingkup berubah ke satu kabupaten (D-008). Modul di luar fokus (budaya, event) ditunda; jadwal roadmap perlu ditinjau bila fokus berubah lagi.
