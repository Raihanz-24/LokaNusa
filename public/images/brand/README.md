# Folder Brand / Logo

Letakkan **file logo asli** di folder ini (`public/images/brand/`).

## Berkas yang diharapkan

| Nama berkas         | Kegunaan                                              | Saran ukuran / format            |
| ------------------- | ----------------------------------------------------- | -------------------------------- |
| `logo.png` atau `logo.svg` | Logo utama (dipakai di header & halaman login) | PNG transparan ≥ 512×512, atau SVG |
| `logo-mark.png`     | (Opsional) hanya ikon/lambang tanpa tulisan            | PNG transparan ≥ 512×512         |

## Catatan

- Format yang disarankan: **PNG transparan** (paling aman) atau **SVG** (paling tajam).
- Jika logo berbentuk persegi panjang (ada tulisan), tetap boleh — nanti akan saya atur ukurannya.
- Setelah file ditaruh di sini, beri tahu saya nama berkasnya, lalu saya akan memprosesnya
  menjadi: tampilan header, tampilan halaman login, favicon, ikon PWA (192/512/maskable),
  dan apple-touch-icon.
- Berkas turunan (favicon, ikon PWA) akan dibuat otomatis oleh saya dari logo utama.
